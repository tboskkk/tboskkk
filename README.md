# Hi, I'm Tyler

Software developer. I build web apps (Vue, Python FastAPI, PostgreSQL) and game tech in Godot: engine tooling, asset pipelines, and getting old games running in a modern engine.

## What I work on

- **Godot engine ports and pipelines.** Reverse-engineering legacy file formats and turning them into native Godot scenes, keeping the original lighting, skyboxes and physics. Case study available on request.
- **[BlockMap](https://github.com/tboskkk/blockmap).** A Godot 4 addon that builds chunked 3D block maps from plain 2D tilesheets, with autotiling, ramps, sprites and edge decoration, for top-down, isometric, side-scrolling and DS-style cameras. Includes a runnable demo.
- **Decompilation tooling.** A reproducible matching-decompilation pipeline (containerized toolchain, CI, asm diffing, progress tracking) for Mario & Luigi: Superstar Saga. See [mlss](https://github.com/tboskkk/mlss).
- **Schedule+.** Multi-location staff scheduling: a coverage rules engine with suggested fixes, an employee portal for time off and shift trades, and Postgres row-level security. React, TypeScript, Supabase. [Live demo](https://scheduling-app-czk.pages.dev) | [Code](https://github.com/tboskkk/scheduling-app)
